# comparison-wiki

Public concept wiki for [Comparabien](https://comparabien.com.pe/) comparison products. Hosted on GitHub Pages.

## Purpose

- Explain **key comparison concepts** in plain language (not implementation details).
- Provide **backlinks** to each Comparabien market site.
- One wiki page per **active product comparator** (derived from internal `ws-` services as a private data dictionary).

## Editorial rule

Public pages describe **concepts** (what the user chooses and what they see). They must not expose private service code, SQL, hashes, or internal field names.
